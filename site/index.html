      05 · Transports

      Two ways to move bytes

      stdio

      Host spawns your process. stdin in, stdout out, stderr for logs. Local only, zero auth, fastest to build.

      Streamable HTTP

      One /mcp endpoint. POST per message, SSE upgrade for streaming, Mcp-Session-Id for state, OAuth 2.1 for auth.
